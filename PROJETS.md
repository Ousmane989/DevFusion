# Mes projets — un projet par branche

Chaque projet a sa **propre branche** `projet/…`, qui ne contient que ses
fichiers (avec son historique). Les projets ne sont plus mélangés.

| Branche | Projet | Contenu |
|---|---|---|
| `projet/karat` | **Karat** + **Karat Logistique** | Plateforme SaaS de boutiques en ligne (karat.fit) et agence de livraison Karat Logistique. Les deux sites partagent le même code serveur (`src/`) ; le dossier `logistique/` est le déploiement Netlify autonome de l'agence ; `video/` contient la vidéo de présentation (Remotion). |
| `projet/portfolio` | **Portfolio & CV** | Portfolio personnel, page des projets et CV (hébergé sur Vercel). |
| `projet/keur-xaleyi` | **Keur Xaleyi** | Plateforme de gestion scolaire (inscriptions, paiements, présences, bulletins). |
| `projet/business-plan` | **Business plan Afrique de l'Ouest** | Analyse de marché et opportunités notées. |
| `projet/bobine-studio-video` | **Bobine** | Studio vidéo IA : création d'avatars et storyboard. |
| `projet/exam-java-joj-dakar` | **Examen Java — JOJ Dakar 2026** | Application console Java + JDBC + MySQL (IntelliJ). |
| `projet/python-gestion-pdf` | **Projet Python (PyCharm)** | Application Python avec base de données (DAO, modèles, menu). |
| `projet/devfusion-site-v1` | **DevFusion — premier site** | Première boutique de baskets en HTML/CSS (Nike, Adidas, Jordan…). |
| `projet/devfusion-ecommerce-animations` | **DevFusion — e-commerce animé** | Boutique e-commerce statique avec système d'animations et espace admin. |
| `projet/ecommerce-prototype-mauritanie-senegal` | **Prototype e-commerce** | Premier prototype web (catégories, commandes) avant Karat. |

> Les anciennes branches (`main`, `master`, `portfolio`, `claude/…`) sont
> conservées telles quelles : les sites en ligne (karat.fit, Karat Logistique,
> portfolio Vercel) se déploient encore depuis elles.
